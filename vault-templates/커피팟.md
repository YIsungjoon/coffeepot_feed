## 기사 목록

```base
filters:
  and:
    - 'file.inFolder("10_Feeds/Articles")'
    - 'note.type == "feed-article"'
    - 'note.source == "COFFEEPOT"'
formulas:
  article: 'file.asLink(note.title)'
  topic: 'if(note.manual_topic, note.manual_topic, if(note.primary_topic, note.primary_topic, if(note.classification_status == "review", "검토 필요", if(note.content_basis, "분류 대기", "미분류"))))'
properties:
  formula.article:
    displayName: 기사
  note.date:
    displayName: 수집일
  note.status:
    displayName: 상태
  formula.topic:
    displayName: 대표 주제
  note.related_topics:
    displayName: 보조 주제
views:
  - type: table
    name: 커피팟 기사
    order:
      - formula.article
      - note.date
      - note.status
      - formula.topic
      - note.related_topics
    sort:
      - property: note.date
        direction: DESC
      - property: note.created_at
        direction: DESC
```

수집 노트에는 커피팟 공개 글 목록의 소개와 원문 링크가 들어갑니다.
