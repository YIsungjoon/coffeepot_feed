[[커피팟|커피팟 기사 모아보기]]

```base
filters:
  and:
    - file.inFolder("10_Feeds/Articles")
    - note.type == "feed-article"
formulas:
  article: file.asLink(note.title)
  topic: if(note.manual_topic, note.manual_topic, if(note.primary_topic, note.primary_topic, if(note.classification_status == "review", "검토 필요", if(note.content_basis, "분류 대기", "미분류"))))
properties:
  formula.article:
    displayName: 기사
  note.source:
    displayName: 출처
  note.date:
    displayName: 수집일
  note.status:
    displayName: 상태
  formula.topic:
    displayName: 대표 주제
  note.related_topics:
    displayName: 보조 주제
views:
  - type: table
    name: 안 읽은 피드
    filters: note.status == "unread"
    order:
      - formula.article
      - source
      - date
      - status
      - formula.topic
    sort:
      - property: published_at
        direction: DESC
      - property: created_at
        direction: DESC
    columnSize:
      formula.article: 271
  - type: table
    name: 전체 피드
    order:
      - formula.article
      - source
      - date
      - status
      - formula.topic
    sort:
      - property: created_at
        direction: DESC
  - type: table
    name: 주제별 기사
    groupBy:
      property: formula.topic
      direction: ASC
    order:
      - formula.article
      - source
      - date
      - status
      - related_topics
    sort:
      - property: created_at
        direction: DESC

```

대표 주제를 직접 지정하려면 기사 속성에 `manual_topic`을 추가하세요. 읽은 기사는 `status`를 `read`로 바꾸세요.
